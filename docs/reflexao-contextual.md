# Reflexao contextual

Aplicativos moveis sao fundamentais para o e-commerce porque aproximam a loja do consumidor e tornam a compra mais rapida, visual e acessivel. Em um app bem organizado, o usuario consegue navegar por categorias, comparar produtos e acessar detalhes importantes sem depender de um site pesado. No consumo de APIs REST com React Native, os principais desafios estao no tratamento de carregamento, falhas de conexao, dados incompletos e organizacao da logica para que a interface continue clara. Neste projeto, o uso do Axios facilita as requisicoes para a DummyJSON, enquanto o Redux Toolkit ajuda a controlar o estado temporario do usuario logado. A divisao entre telas, componentes, servicos e store tambem conecta o desenvolvimento com boas praticas vistas em aula, pois separa responsabilidades e torna o aplicativo mais facil de manter. Assim, o catalogo implementado demonstra conceitos essenciais de mobile: navegacao entre telas, consumo de API, validacao de formulario, exibicao de listas e experiencia responsiva.
